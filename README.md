# Автоматизация UI-тестирования веб-сервиса «Stellar Burgers»

Этот проект представляет собой пакет автономных UI-тестов для проверки веб-интерфейса сервиса «Stellar Burgers».

## Описание проекта

Тесты написаны на Python с использованием фреймворка **Pytest** и библиотеки **Selenium WebDriver**. Для обеспечения стабильности и отказоустойчивости тестов, часть логики была переведена на выполнение нативных JavaScript-скриптов через `driver.execute_script()`. Проект тестирует логику в браузерах **Google Chrome** и **Mozilla Firefox**.

**Особенности архитектуры реализации:**
* **Page Object Model (POM):** Вся логика взаимодействия с элементами изолирована внутри классов страниц (`BasePage`, `MainPage`, `OrderFeedPage`). 
* **Гибридные фикстуры (UI + API):** Подготовка тестовой среды перенесена на бэкенд. Фикстура `_login_user` регистрирует уникального пользователя через API-запрос, авторизует его в браузере и удаляет аккаунт методом `DELETE`.
* **Самозалечивающиеся методы (Self-healing):** Метод клика по кнопке оформления заказа снабжен блоком `try/except` для перехвата `ElementClickInterceptedException`. При зависании полупрозрачных оверлеев модальных окон в Firefox страница автоматически обновляется без падения теста.

**Проект покрывает следующие функциональные блоки:**
* **Главная страница и Конструктор (`MainPage`):** Проверка переходов между вкладками «Конструктор» и «Лента заказов», открытие и закрытие модального окна деталей ингредиента по крестику, параметризованная проверка увеличения счётчиков при добавлении булок (х2) и соусов (х1).
* **Лента заказов (`OrderFeedPage`):** Проверка динамического увеличения глобальных счётчиков «Выполнено за всё время» и «Выполнено за сегодня» при оформлении заказа авторизованным пользователем, а также проверка появления номера заказа на доске «В работе».

## Как установить проект

1. Клонируйте репозиторий с проектом или распакуйте архив в рабочую папку.
2. Откройте терминал в папке проекта, активируйте ваше виртуальное окружение и установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Как запустить автотесты

Вы можете запустить весь пакет тестов целиком для обоих браузеров или каждый модуль по отдельности.

* **Запуск абсолютно всех тестов проекта (Chrome + Firefox):**
  ```bash
  pytest tests/ 
  ```
* **Запуск конкретного функционального модуля:**
  * Проверка конструктора и ингредиентов: `pytest tests/test_main_functionality.py 
  * Проверка счётчиков и ленты заказов: `pytest tests/test_order_feed.py

## Генерация отчётов

Интерактивные отчёты по результатам прогона тестов формируются с помощью фреймворка **Allure**. 

Сборка и просмотр чистого отчёта через локальный веб-сервер:
```bash
allure serve allure-results
```
